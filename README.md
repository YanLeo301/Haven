For the moment this is the base for a realtime multiplayer browser game. The application uses a Websocket connection to synchronise the positions of the players. Every connected player is rendered as a rectangle for now (white for local player, red for remote players). There is no gameplay yet, except moving around.

## Frameworks

- [Phaser](https://github.com/phaserjs/phaser)
- [Spring-Boot](https://github.com/spring-projects/spring-boot)
